# `t-photos/` — Team photos

Pending. The team photo and individual member photos required by WRO
Future Engineers documentation rules will be added here after the
official team photo session.

Required (per WRO submission guidelines):

- One **team photo** with all members present, in matching team apparel
  if available, taken against a plain background.
- One **funny / candid photo** of the team (optional but encouraged) —
  used by organizers in announcements and team profiles.

Until those photos are taken, this folder intentionally contains only a
`.gitkeep` so the folder is preserved in version control.
