# Pixy2/2.1 — временная камера вместо OpenMV (v13)

**Контекст:** 2026-06-12 повреждён сенсор-модуль OpenMV H7 Plus. Pixy подключается
на **те же пины UART2**, прошивка робота уже умеет оба бэкенда
(`CAMERA_BACKEND` в `wro_config_v13.h`, §12 — сейчас стоит `PIXY2`).
FSM, failsafe-логика и телеметрия не менялись.

---

## 1. Какая у нас Pixy?

- **Pixy2 / Pixy2.1** — маленькая (~40 мм), кнопка сверху. → всё по этому гайду.
- **Pixy1 (CMUcam5)** — большая плата ~55 мм, 2014 года. → СТОП, протокол другой,
  сказать Claude — драйвер нужен другой.

## 2. Подключение к роботу

10-пиновый разъём Pixy (IDC 2×5, пин 1 помечен стрелкой/треугольником):

| Pixy | Провод | ESP32-S3 |
|---|---|---|
| pin 4 (UART TX) | → | GPIO17 (CAMERA_RX) |
| pin 1 (UART RX) | ← | GPIO18 (CAMERA_TX) |
| pin 2 (5V) | ← | 5V с бака (Pixy ест ~140 мА) |
| pin 6 (GND) | ↔ | GND |

Логика Pixy — 3.3 В, для S3 совместимо напрямую.

## 3. PixyMon: один раз настроить

1. Установи PixyMon v2 (pixycam.com → downloads), подключи Pixy по USB.
2. **Интерфейс:** Configure → Interface → `Data out port` = **UART**,
   `UART baudrate` = **115200** (заводское 19200 — обязательно сменить!).
3. **Сигнатуры — учить строго в этом порядке** (прошивка робота ждёт именно так):
   - **1 = красный столбик**
   - **2 = зелёный столбик**
   - **3 = оранжевая линия**
   - **4 = синяя линия**
   - **5 = маджента-парковка**

   Action → Set signature 1..5 (или кнопкой на камере). Учить **при том же
   свете, что и заезд**, объект на 30–60 см.
4. Подкрути per-signature range так, чтобы блок держался стабильно, а пустая
   сцена не давала ложных блоков.
5. File → Save Parameters (сохранить во флеш Pixy).

## 4. Калибровка дистанции (FOCAL)

1. Красный столбик ровно на **50 см** от объектива.
2. Смотри в телеметрии робота `redDist` (камера должна быть подключена к S3).
3. Новое значение: `PIXY_FOCAL_PIX_new = PIXY_FOCAL_PIX_тек × redDist / 50`.
4. Впиши в `wro_config_v13.h` §12, перепрошей, проверь: на 50 см → ~50, на 100 см → ~100.

Дефолт 190 рассчитан на Pixy2.1 (~80°). У Pixy2 (60°) будет ближе к 270.

## 5. Проверка связки

1. Target 11 (`wro_v13_main.cpp`), боот-лог: `Camera UART2 ready — Pixy2 backend`.
2. Покажи камере красный столбик → в телеметрии `redDist` < 999 и `redX` меняется
   при движении столбика влево/вправо.
3. Зелёный → `greenDist/greenX`. Оранжевая/синяя линия на полу в нижней части
   кадра → биты ModeFlag. Маджента → бит 4 + extraTag.
4. Убери всё из кадра → дистанции 999, флаги 0, камера остаётся online.

⚠️ Target 12 (`diag_test_camera.cpp`) сделан под текстовый протокол OpenMV —
для Pixy он покажет мусор, это нормально. Проверяй через телеметрию target 11.

## 6. Вернуть OpenMV (если модуль оживёт / приедет новый)

`wro_config_v13.h` §12: `#define CAMERA_BACKEND CAMERA_BACKEND_OPENMV` → перепрошить.
Больше ничего менять не надо.

## Известные отличия от OpenMV

- Pixy сама делает экспозицию/баланс — фиксации, как на OpenMV, нет. Поэтому
  **переучить сигнатуры на месте соревнования** (5 минут) — обязательный пункт
  чек-листа.
- Дистанция считается из высоты блока Pixy — после смены камеры обязательно
  перекалибровать FOCAL (§4) и прогнать Dynamic Offset на треке.
- Крепление: у Pixy свои отверстия (M2.5 по углам) — старый OpenMV-маунт не
  подходит, временно хомут/стяжка, высота и наклон — как у OpenMV.
