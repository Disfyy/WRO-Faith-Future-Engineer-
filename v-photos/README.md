# `v-photos/` — Vehicle photos

Engineering photos of the assembled Team Faith WRO v13 robot, one per
canonical view. WRO Future Engineers documentation requires photos of the
vehicle from every side so judges can evaluate mechanical design without
seeing the robot in person.

## Photos

| File | View | What's visible |
|---|---|---|
| [`top.jpeg`](top.jpeg) | Top-down | ESP32-S3-DevKitC-1, OpenMV H7 Plus camera mount, IMU, wiring harness |
| [`bottom.jpeg`](bottom.jpeg) | Bottom | Drivetrain layout, motor + gearbox, both AS5600 encoder magnets, chassis frame |
| [`front side.jpeg`](front%20side.jpeg) | Front | Steering linkage, front VL53L1X ToF, camera field-of-view direction |
| [`left side.jpeg`](left%20side.jpeg) | Left | Side VL53L1X ToF, battery placement, cable routing |
| [`right side.jpeg`](right%20side.jpeg) | Right | Motor driver (BTS7960), power distribution, E-Stop button access |

> 📝 **Captions are provisional** — they reflect what should be visible in
> each view based on the v13 build. Update this table before submission if
> any photo shows something different, and re-take any photo where the
> labeled component isn't actually visible.

## Photo requirements (per WRO Future Engineers documentation rules)

- At least one photo from each of the 6 standard views (top, bottom,
  front, back, left, right). Currently missing: **back view**.
- Photos should be sharp, well-lit, and taken against a plain background.
- The robot should be in its competition configuration (no debug wires,
  no removed panels) when photographed for the final submission.
