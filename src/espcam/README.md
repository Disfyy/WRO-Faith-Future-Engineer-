# ESP32-CAM аварийное зрение (план Б вместо OpenMV)

**Зачем:** сенсор-модуль OpenMV H7 Plus повреждён (2026-06-12), до соревнования 5 дней.
Эта прошивка превращает ESP32-CAM в «поддельный OpenMV»: она шлёт **тот же UART-кадр
v3.1** (`RedX,RedDist,GreenX,GreenDist,ModeFlag,ExtraTag*XX\n`, 115200 8N1), поэтому
**прошивка робота (wro_v13_main.cpp) не меняется вообще**.

Файл: `espcam_vision/espcam_vision.ino`

---

## 1. Прошивка платы

Нужен USB-TTL адаптер (CH340/FTDI/CP2102) или подставка ESP32-CAM-MB.

| USB-TTL | ESP32-CAM |
|---|---|
| TX | U0R |
| RX | U0T |
| GND | GND |
| 5V | 5V |

1. Замкни **IO0 → GND** проводом.
2. Подключи USB — плата в режиме загрузки.
3. Arduino IDE: плата **"AI Thinker ESP32-CAM"** (Tools → Board → esp32).
4. Открой `espcam_vision.ino` → Upload.
5. После «Done uploading» сними перемычку IO0, нажми RST.
6. В Serial Monitor (115200) должно появиться `[CAM] OV2640 up` и `[NET] tuner at http://192.168.4.1`.

**Если плата не AI-Thinker** (нет надписи) — сверь распиновку камеры с
документацией конкретной платы, она может отличаться.

## 2. Подключение к роботу

| ESP32-CAM | Куда |
|---|---|
| GPIO13 (TX) | ESP32-S3 **GPIO17** (UART2 RX — туда, где был TX OpenMV) |
| GND | GND робота |
| 5V | 5V с бака (≥500 мА). **НЕ** с пина 3V3 |

- **GPIO12 не подключать никуда** (страповый пин — плата не загрузится).
- Линия односторонняя: камера только передаёт, как и OpenMV.

## 3. Настройка порогов (вместо OpenMV IDE)

1. Подключись с ноутбука/телефона к WiFi **WRO-CAM**, пароль **wro2026fe**.
2. Открой **http://192.168.4.1** — там живая картинка, счётчики пикселей по
   каждому цвету и ползунки порогов (YCbCr: Y — яркость, Cb — «синева», Cr — «краснота»).
3. Ставь объект перед камерой → двигай ползунки, пока `px` объекта большой и
   стабильный, а на пустой сцене — ноль.
4. Камера: сначала сними галочки AEC/AGC/AWB и подбери exp/gain так, чтобы белый
   пол был белым (это аналог нашей фиксации экспозиции на OpenMV).
5. **Жми SAVE** — настройки сохраняются во флеш и переживают перезагрузку.

Порядок цветов на странице: RED, GREEN, ORANGE, BLUE, MAGENTA.

## 4. Калибровка дистанции (FOCAL)

1. Красный столбик ровно на **50 см** от объектива.
2. На странице смотри `RED ... h:<пиксели>`.
3. `focal = 50 * h / 10` → впиши в поле focal → SAVE.

## 5. Проверка связки с роботом

На ESP32-S3 в Serial Monitor должны пойти пакеты камеры (как раньше от OpenMV).
Если робот пишет camera offline — проверь: GPIO13→GPIO17, общий GND, 115200.

## 6. ⚠️ БОЕВАЯ СБОРКА (перед соревнованием)

В начале `espcam_vision.ino` поставить:

```cpp
#define ENABLE_WIFI_TUNER  0
```

и перепрошить. **Правила WRO запрещают радиосвязь на машине во время заезда.**
Пороги уже сохранены во флеше — после перепрошивки они остаются.

## Траблшутинг

| Симптом | Причина |
|---|---|
| `Brownout detector was triggered` в логе | Слабое питание 5V — толще провода, не от USB-хаба |
| `[CAM] init attempt N failed` | Шлейф камеры OV2640 не защёлкнут на плате |
| Быстро мигает красный LED | Камера не инициализировалась — робот уйдёт в failsafe (это правильно) |
| Редкое мигание LED | Всё работает, кадры идут |
| Пол «краснит» | Сузить RED по Cb (поднять Cbmin) и выключить AWB |
