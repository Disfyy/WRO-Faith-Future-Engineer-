# `other/` — Engineering documentation by WRO topic

The WRO Future Engineers rubric scores three engineering areas separately.
This folder organises Team Faith's design rationale by those three areas
so a judge can read each concern in isolation. Each subfolder contains a
self-contained writeup that links out to the canonical sources of truth
(source code, schematics, detailed guides) elsewhere in the repo.

| Area | Folder |
|---|---|
| Drivetrain, steering, chassis, speed control | [`mobility-management/`](mobility-management/) |
| Battery, power distribution, sensor selection & integration | [`power-and-sense-management/`](power-and-sense-management/) |
| Obstacle Challenge strategy, pillar handling, parking | [`obstacle-management/`](obstacle-management/) |

> Authoritative documentation continues to live in `docs/` and `src/`.
> Files here are explanatory writeups *about* those sources, not copies of them.
