# `video/` — Demonstration video

Pending. The WRO Future Engineers category requires a video showing the
robot completing each challenge:

- **Open Challenge** — three full laps on the track with randomized
  inner/outer wall sections.
- **Obstacle Challenge** — three laps with red/green traffic-sign
  pillars + the magenta parking-lot finishing maneuver.

## How this will be linked

Submitted videos are typically hosted on **YouTube** (unlisted or public)
and linked from this README rather than checked into the repo — `.mp4`
files are too large for normal Git workflows.

When the first clean run is captured (per the calibration protocol, this
follows Stage 4 — first reliable 3-lap Open Challenge runs), this file
will be updated with:

- YouTube URL
- Run date and conditions (lighting, battery voltage, firmware commit)
- Brief description of what's shown

Until then, this folder intentionally contains only a `.gitkeep`.
